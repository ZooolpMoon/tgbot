## 约定

- 所有文档里的示例用户名统一写成 `@YourBot`，Worker 地址写成 `your-worker.<subdomain>.workers.dev`，仓库写成 `<owner>/<repo>`。
- 涉及具体数值（积分、额度、阈值、上限）时，文档会写**默认值 + 改哪里**；代码里的常量文件是 `src/config/constants.js`。
- 文档与代码不一致时，以代码为准，欢迎提 Issue 指出。
