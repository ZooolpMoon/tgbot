# 📖 指令一览

[返回首页](../README.md) · [文档索引](README.md)

指令由 `src/handlers/commands/registry.js` 的注册表统一管理：权限、别名、仅私聊、功能开关判定、`/help` 文案、输入框菜单都由它派生。

## 普通用户

| 指令 | 别名 | 说明 |
|------|------|------|
| `/start` | — | 欢迎信息、当前积分与额度 |
| `/help` | `/h` | 指令列表（按身份与场景自动裁剪） |
| `/checkin` | `/sign` | 每日签到，连续签到奖励递增 |
| `/points` | `/mypoints` | 积分流水（可翻页） |
| `/rank` | `/top` `/leaderboard` | 积分排行榜 Top 10（含自己的名次） |
| `/game` | `/games` | 游戏大厅 |
| `/profile` | — | 个人信息卡片（积分 / 签到 / 任务 / 额度） |
| `/setlang` | — | 切换 AI 回复语言（`zh` / `en`） |
| `/setprompt` | — | 设置或清空自定义 AI 偏好 |
| `/clear` | — | 清空当前场景的对话记忆 |
| `/shop` | `/store` | 积分商城（仅私聊） |
| `/orders` | `/myorders` | 我的订单（仅私聊） |
| `/bag` | `/backpack` `/items` | 我的背包：查看与使用已购买的虚拟物品（仅私聊） |
| `/redeem` | `/use` | 用兑换码领积分（仅私聊） |
| `/transfer` | `/pay` `/give` | 把积分转给其他用户（可回复对方消息后只写金额） |
| `/lottery` | `/draw` `/choujiang` | 每日抽奖：每天 1 次免费，也可花积分抽 |
| `/report` | `/jubao` | 举报违规（**仅群聊**，需先回复违规消息） |
| `/appeal` | `/shensu` | 对被处置提出申诉（仅私聊） |

> 处置、举报、申诉都**只认指令**，机器人不会从普通发言里猜「封禁 / 拉黑 / 踢了」。

## 管理员

> 需要先在私聊发 `/admin` 解锁；解锁状态 30 分钟内有效。

| 指令 | 说明 |
|------|------|
| `/admin` | 打开管理控制台 |
| `/admins` | 管理员与权限（**仅拥有者**）：引导式增删管理员、改角色 |
| `/users` / `/users_group` | 私聊 / 群聊场景列表 |
| `/stats` | 使用统计 |
| `/addpoints <场景ID\|用户ID\|@用户名> <数量>` | 增减某用户的全局积分（负数表示扣分） |
| `/clearmem me \| <群ID> \| <群ID> <用户ID>` | 清除当前 / 整群 / 某群某成员的 AI 记忆 |
| `/kb` | 知识库面板：上传资料、文档列表、检索测试（群里打开 = 本群知识库） |
| `/guard` | 群规执法面板：编辑群规、默认处置、预警关键词、处置记录 |
| `/rules` / `/setrules <正文>` | 查看 / 设置本群群规 |
| `/ban <用户ID\|@某人> [理由]` | 封禁（群里会先校验理由再弹确认卡片） |
| `/kick` / `/groupban` / `/mute` | 踢出 / 群内封禁 / 限时禁言（都需理由） |
| `/unban` / `/unmute` | 解除封禁 / 解除禁言 |
| `/code_new <积分> [次数] [有效天数]` / `/code_list` | 生成 / 管理兑换码 |
| `/broadcast <内容>` | 群发给所有未封禁的私聊用户（二次确认、支持断点续发） |
| `/shop_admin` / `/shop_add` / `/shop_edit <商品ID>` | 商城管理 / 添加商品 / 编辑商品（仅私聊） |
| `/syncmenu` | 把指令同步到输入框菜单 |

> `/ban` `/unban` `/kick` `/groupban` `/mute` `/unmute` `/rules` 在群里也允许**本群管理员**
> （creator / administrator）使用，不需要机器人管理员的 `/admin` 解锁；
> 群规面板 `/guard` 与 `/setrules` 仍然只给机器人管理员。

### 角色与权限（v3.0.0）

管理指令不再是「只有拥有者能用」，而是按**角色 → 能力**判定：

| 角色 | 能做什么 | 不能做什么 |
|------|---------|-----------|
| 👑 拥有者（`MY_TELEGRAM_ID`） | 全部，含管理员与权限管理 | — |
| 🛡️ 管理员（后台授权） | 用户管理、商城、知识库、群规配置、功能开关、自动删除、兑换码、群发、日志统计、执法 | ❌ 增减管理员 |
| ⚔️ 执法员（后台授权） | 只能执法：`/ban` `/unban` `/kick` `/groupban` `/mute` `/unmute` `/rules`，以及处理群规确认卡片与申诉 | ❌ 进后台、❌ 用户管理 / 商城 / 知识库 |

入口：管理控制台 → 👑 管理员与权限（只有拥有者能进）。加完人记得让对方先发一次 `/admin` 解锁。

## 输入框命令菜单

聊天框里输入 `/` 会弹出指令列表。**菜单由命令注册表自动生成**：新增命令不需要改菜单代码，部署后自动同步（用内容哈希判断，只有命令变化才调用 Telegram API，检查放在 `waitUntil` 不阻塞请求）。

作用域跟着**多管理员模型**走（菜单里能看到的 = 实际能用的）：

| 作用域 | 内容 |
|--------|------|
| 所有私聊 | 普通用户命令 |
| 所有群聊 | 普通命令（自动去掉「仅私聊」的命令） |
| 👑 拥有者私聊 | 全部管理指令 |
| 🛡️ 每个管理员 / ⚔️ 执法员私聊 | 只挂他有能力用的（执法员看不到兑换码、群发、用户管理） |
| 每个群的群管理员（`chat_administrators`） | 普通命令 + 带 `groupAdmin` 标记的执法指令 |

按身份裁剪靠命令表里的 `capability` 与 `groupAdmin` 标记，**新增管理指令时带上 `capability` 就自动生效**。授权 / 改角色 / 移除管理员时会立刻刷新菜单；被移除的人那份会被清空，不会在输入框里留下点不动的命令。

Telegram 对 `BotCommand` 的限制（名称 `^[a-z0-9_]{1,32}$`、描述 3~256 字）在生成时已自动过滤，命令名里的 `/` 会自动去掉。

菜单没更新时，管理员执行 `/syncmenu` 强制同步。`/help` 用的是同一套可见性规则（`capability` + `groupAdmin`）。

## 群聊里的行为差异

| 场景 | 行为 |
|------|------|
| 私聊 | 所有消息都会被处理；回复内容保留 |
| 群聊 | 只有 **@机器人** 或以 **`/指令`** 开头的消息会被响应 |
| 群聊 · 指令类回复 | 默认 5 秒后自动删除（避免刷屏），时长可在「🗑️ 自动删除」里按类型调整 |
| 群聊 · AI 回复 / 公告 / 卡片 | 默认保留；管理员可分别设置成 N 秒后删除（0 = 不删除） |
| 群聊 · 普通聊天 | 不回复，但会做一次静默关键词预警（若管理员开启了预警） |

## 消息自动删除

群聊里机器人自己发的消息，可以按**消息类型**分别设置保留时长（0 秒 = 不删除）：

| 类型 | 默认 | 覆盖的消息 |
|------|------|-----------|
| ⚙️ 指令回执 | 5 秒 | 指令结果、用法提示、错误提示 |
| 🛡️ 执法回执 | 5 秒 | 封禁 / 踢出 / 禁言的结果提示 |
| 🖲️ 确认卡片 | 保留 | 需要留时间点击的处置 / 申诉卡片 |
| 🤖 AI 回复 | 保留 | 群聊里 AI 的回答 |
| 📢 系统通知 | 保留 | 处置公告、到期提醒与每日概况 |

入口：管理控制台 → 🗑️ 自动删除。设置分两级——**本场景**优先于**全局默认**，
群里改的是「这个群」，且群内所有成员共享同一份设置；私聊消息本来就不删。

相关：[群规执法](group-guard.md) 的举报与预警机制。
