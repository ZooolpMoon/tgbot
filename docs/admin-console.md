# 👑 管理后台导览

[返回首页](../README.md) · [文档索引](README.md)

入口：私聊发 `/admin`（只有 `MY_TELEGRAM_ID` 能用）。解锁状态 30 分钟有效，之后点击面板里的按钮会自动续期。

```
👑 管理控制台
├── 👥 用户管理
│   ├── 💬 私聊用户        → 用户列表 → 场景编辑 → 📇 用户详情
│   ├── 👥 群组用户        → 群列表 → 群成员 → 场景编辑
│   └── 🚫 封禁名单        → 一键解封
├── 📚 知识库              → 添加文档 / 文档列表 / 检索测试 / 重建索引
├── 📜 群规执法            → 编辑群规 / 群规历史 / 默认处置 / 默认禁言 / 预警 / 处置记录
├── 🛒 商城管理            → 商品列表 / 添加商品 / 待处理订单 / 全部订单
├── 🎟️ 兑换码              → 生成 / 启停 / 列表
├── ✅ 每日任务            → 引导式增删改 / 全勤奖
├── ⚙️ 功能开关            → 全局 / 群聊场景 / 私聊场景 三级
├── 📋 操作日志            → 按 用户 / 商城 / 执法 / 知识库 / 任务 / 系统 筛选
├── 📊 运行状态            → D1 / Workers AI 绑定情况
├── 📈 使用统计            → 用户数、活跃场景、签到、积分总量…
└── 🧹 清空我的记忆
```

每个面板都用按钮操作，**不需要记指令**。

## 用户管理

| 面板 | 能做什么 |
|------|---------|
| 💬 私聊用户 | 分页浏览所有私聊场景 |
| 👥 群组用户 | 先选群（显示群 ID 与人数）→ 看该群成员 → 点进成员 |
| 场景编辑 | 改积分、看流水、调每日额度与冷却、开关功能、封禁 / 解封、清空记忆、删除场景 |
| 📇 用户详情 | 一屏聚合：身份、积分、封禁状态、签到（累计 / 连续）、今日任务、今日消息量、最近 3 条积分流水、最近 3 笔订单、最近 3 次群内处置 |
| 🚫 封禁名单 | 列出所有被封禁用户，一键解封 |

**积分与封禁是用户级的**（跨场景共享），其余配置都是场景独立的。

## 知识库

见 [知识库（RAG）](knowledge-base.md)。面板里可完成：添加文档（粘贴文本或发 `.txt`/`.md`/`.docx`/`.pdf`）、文档列表、启停、删除、检索测试、重建索引、调整文档生效范围。

## 群规执法

见 [群规执法](group-guard.md)。面板里可完成：引导式编辑群规、群规历史与回滚、默认处置方式、默认禁言时长、主动预警开关与关键词、执法总开关、处置记录（含一键撤销）。

## 每日任务

- 任务 = **触发条件**（代码定义，机器人只能观测到有限行为）+ **名称 / 提示 / 奖励**（管理员可改）
- 引导式添加：选触发条件 → 输入任务名称 → 完成提示 → 奖励积分
- 支持改名称 / 改提示 / 改奖励 / 停用启用 / 删除（二次确认）
- 同一个触发条件可以挂多个任务
- 全部启用任务完成后发放「全勤奖」（可配置，0 表示不发）
- 列表分页显示，每页 6 个

内置触发条件：

| 触发条件 | 默认奖励 | 说明 |
|---------|---------|------|
| `checkin` 完成每日签到 | +5 | 发送 `/checkin` |
| `chat` 和 AI 聊一次 | +3 | 直接发消息；群聊里 @ 机器人 |
| `game` 玩一局游戏 | +3 | 发送 `/game` 开一局 |
| `shop` 在商城兑换一次 | +2 | 发送 `/shop`（仅私聊） |
| `redeem` 使用一次兑换码 | +2 | 发送 `/redeem <码>`（仅私聊） |

## 功能开关

8 项能力可独立开关，且是**三级**的：

| 层级 | 作用范围 |
|------|---------|
| 🌍 全局设置 | 所有私聊与群聊的默认值 |
| 👥 群聊场景 | 只影响某个群（不设置则跟随全局） |
| 💬 私聊场景 | 只影响某个用户（不设置则跟随全局） |

可开关项：

| key | 名称 | 影响范围 |
|-----|------|---------|
| `ai` | AI 对话 | 私聊 / 群聊里的 AI 回复 |
| `kb` | 知识库检索 | AI 回答前是否检索知识库 |
| `guard` | 群规执法 | 自然语言处置、举报、预警 |
| `game` | 游戏大厅 | 骰子、老虎机、硬币、转盘 |
| `checkin` | 每日签到 | 连续签到奖励 |
| `shop` | 积分商城 | 商品浏览与兑换 |
| `redeem` | 兑换码 | 用兑换码领积分 |
| `tasks` | 每日任务 | 完成任务领积分 |

生效顺序：**场景显式设置 → 全局设置 → 默认开启**。关掉后指令、按钮回调、AI 回复都会被拦下并给出提示，不会留下半截状态；场景页支持「🔄 全部恢复跟随全局」。

## 兑换码

- `/code_new <积分> [次数] [有效天数]`：次数 0 = 不限，天数 0 = 永久
- 每个码**每人限兑一次**（数据库唯一约束保证）；可随时停用 / 启用
- 列表页展示面额、已用 / 总次数、状态与过期日

## 群发通知

- `/broadcast <内容>` → 二次确认 → 分批发送给所有**未被封禁且私聊过机器人**的用户
- 分批写入进度游标，单次时间预算用尽会提示「继续发送」，支持断点续发
- 正文按纯文本推送（不解析 HTML），最长 3500 字符

## 操作日志（审计）

所有管理动作都会写入 `admin_logs`，支持按类别筛选，翻页时保留筛选条件：

| 筛选 | 包含的动作 |
|------|-----------|
| 👥 用户 | 封禁 / 解封、调整积分、调限额 / 频率、删除场景、清空记忆 |
| 🛒 商城 | 商品增删改与上下架、订单完成 / 取消退款、群发 |
| 🛡️ 执法 | 发起 / 执行 / 取消处置、撤销、申诉处理、群规变更与开关 |
| 📚 知识库 | 文档新增 / 启停 / 删除、范围调整 |
| ✅ 任务 | 每日任务增删改与启停、全勤奖、功能开关切换 |
| ⚙️ 系统 | 兑换码生成与启停等其它动作 |

## 使用统计

`/stats` 或后台「📈 使用统计」会汇总：用户总数、群聊场景数、已封禁用户、今日签到人数、今日任务完成次数、今日活跃场景、今日成功请求、用户积分总量、管理员操作记录条数与额度时区。
